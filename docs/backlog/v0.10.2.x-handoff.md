## Orchestration playbook (what worked this session — keep doing it)

- **Opus subagents, detailed prompts, disjoint file allowlists**, each carrying the binding quality bar verbatim: *DRY — single actions are degenerate cases of batch; never two ways to do a thing* (user's core directive); DDD layer rules (import-linter enforces; "needing a new exception is a design smell to report, not add"); precise non-generic naming; constraint-stating comments, never narration; **NO suppressions** (repo bans + ratchet).
- **Your verification pass is real work**: read the diffs, adversarially check the subtle seams (savepoint/commit boundaries, cross-agent contracts), then run the full gate battery yourself — agents gate only their scope while others' edits are in flight, so their "green" is provisional.
- **Review before push**: the user runs `/code-review` (medium or high). The skill **stalls between phases** — if a notification says "one finder remains" or "waiting for verdict" and nothing follows, `SendMessage` the agent to resume; report final findings via `ReportFindings` (once, ranked); fix ALL confirmed findings via a remediation agent wave before the tag moves. Every review this session found real bugs — don't skip it for "small" waves.
- **Tags**: assemble commits on main, `git tag -f v0.10.2.N` onto the final commit, push main+tag together (tag push triggers deploy). `git commit --amend` is blocked by the permission classifier — use new commits.
- **Docs in parallel**: stage CHANGELOG/backlog entries while agents run, reconcile against what actually landed. Version bump ritual per `.claude/rules/version-management.md` (pyproject → `uv sync` → `pnpm --prefix web sync-api` → docs → `check_backlog.py`).
- **Gate battery** (run before every commit-that-ships): `uv run ruff check src/ tests/ scripts/` + `format --check`; `uv run basedpyright src/`; `uv run lint-imports`; `bash scripts/check_ratchet.sh`; `uv run pytest -q`; `uv run pytest -m "" tests/integration -q`; `pnpm --prefix web test`; `pnpm --prefix web check`; `uv run python scripts/check_backlog.py`.
